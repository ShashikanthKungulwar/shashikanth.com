CodeSense AI: Local-First Code Review Assistant

Self Project  |  FastAPI, Qwen2.5-Coder, Ollama
  • Built a code review tool running inference against a local LLM (qwen2.5-coder:7b via Ollama), exposing style review, complexity analysis and edge-case generation over FastAPI with a React/Vite/Monaco frontend, SQLite persistence and Docker Compose.
  • Designed a swappable provider abstraction so adding a cloud backend (Groq) required one new file and one factory entry — no change to routes, services, schemas or frontend; enforced the boundary with an architectural fitness test that fails the build if httpx is imported outside providers/.

Text-to-SQL via Dynamic Few-Shot Prompting

Course Project, 3 members  |  LLMs, RAG, SentenceTransformers
  • Advised by Prof. Arnab Bhattacharya and Prof. Subhajit Roy. Built a retrieval-augmented pipeline that embeds each question with a SentenceTransformer (all-MiniLM-L6-v2) and retrieves the top-K most cosine-similar solved examples from a held-out knowledge base to construct the prompt.
  • Ran a controlled comparison of four prompting strategies across two models (Gemini 2.5 Flash, Llama 3.1 8B) and two benchmarks (Spider, BIRD), evaluated by execution accuracy on a 200-sample subset per dataset.
  • Raised Gemini execution accuracy on BIRD from 33.0% to 52.5% and on Spider from 61.0% to 74.5% over the zero-shot baseline; Llama improved from 8.0% to 32.5% on BIRD.
  • Swept retrieval depth K = 1–5, finding gains saturate near K = 3–4 and attributing the ceiling to context saturation and BIRD's implicit foreign keys and non-standard column naming.
  • RAG
  • Gemini 2.5 Flash
  • Llama 3.1 8B
  • Spider / BIRD
  • SentenceTransformers

Distributed 3D Stencil Solver with MPI Halo Exchange

Course Assignment, CS633 — 5 members  |  C, MPI, HPC
  • Built a distributed d-point stencil solver over a px × py × pz Cartesian process grid with six-neighbour ghost-cell halo exchange.
  • Eliminated pack/unpack overhead by communicating non-contiguous halo faces through MPI derived datatypes.
  • Overlapped communication with computation via non-blocking sends/receives, computing interior points during message transit; replaced array copies with pointer swapping.
  • Benchmarked on PARAM Rudra across 32–96 processes, measuring a consistent 1.17–1.20× speedup at 240³, with communication overhead limiting gains at smaller sizes.
